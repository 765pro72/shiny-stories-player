# 实时超分：Anime4K / CuNNy（2026-11-13）

新增 CuNNy NVL 四档可选，最高 8×32、2× 输出，不额外叠加 Restore；说明、许可和数值验证见 [CuNNy移植说明.md](CuNNy移植说明.md)。以下为保留的 Anime4K 选项。

主页的“看板设置”内选择画质，剧情右上角及语音试听区也有同一设置。切换会保存到桌面用户配置，不改原始图片、模型或离线缓存。

| 选项 | 实际处理 |
| --- | --- |
| 原图 | 原始 PIXI 渲染 |
| 流畅 S / 清晰 M / 精细 L · 2× | Anime4K 对应 CNN 模型，宽高各 2 倍 |
| 最高 UL · 2× | Clamp + Restore CNN UL + Upscale CNN UL |
| 最高 UL · 4× | 在 UL 2× 基础上再执行一次 Upscale CNN UL |

每次启动默认关闭，选择“原图”；本次会话中手动开启后，各视图共享档位。最高可选 UL 4×。主页和剧情的逻辑画布为 1136×640，最高档输出 4544×2560；这是实时超分结果，不是素材原生 4K，也不能恢复所有原图丢失的信息。处理角色与场景合成后的完整帧，避免分别修改 Spine 图集造成拼缝、尺寸和坐标错位。角色动画、点击区域、对话推进沿用原播放器。

自动适配：跳过启动编译阶段，持续低帧率才按 UL 4×→UL 2×→L→M→S→原图调整。每次调整都会弹出 12 秒可关闭提示，说明原档位、新档位和原因；设置和剧情菜单显示实际生效档位。自动调整不覆盖用户保存的偏好，新视图仍从偏好档位尝试。显卡不支持、处理报错或上下文丢失会恢复原图并提示。

当前覆盖：主页（角色与事务所背景）、剧情演绎（场景、角色和画布字幕）、语音试听动态偶像，以及卡片相册的静态卡面和视频。相册保留原图保存，并可另存当前档位处理后的 PNG；视频保留原生播放、音量和进度控制。HTML 菜单保持浏览器原生文字渲染。

实现采用 [Anime4K.js](https://github.com/monyone/Anime4K.js) 对 [Anime4K 4.0.1](https://github.com/bloc97/Anime4K) 的 WebGL 移植。固定提交 be5ffeae44684d6a52456f8218d0cc04e58639c0，MIT 许可。仅修改 Clamp 的 alpha 通道保留逻辑；RGB 权重不改，不使用 GAN 或人脸重绘。许可与来源在 `public/vendor/anime4k/`，源码在 `vendor/anime4k/src/`。

运行时组件全部内置，无需联网下载模型；轻量版仍按原规则在线读取游戏原始资源，保存离线资源仍需显式点击下载。

维护：`node scripts/build-anime4k.cjs` 用固定 esbuild 0.25.12 构建内置 JS，仅重新构建时需要 npm；`node scripts/test-anime4k.cjs` 用隔离 Electron GPU 场景验证真实像素变化、透明边缘、所有档位、反复切换、尺寸同步、上下文丢失恢复、自动降档提示及偏好保留。报告在 `exports/anime4k-gpu-verification.json`。

2026-11-13 可选叠加档位：实时超分菜单新增“叠加 · CuNNy 8×32 → Anime4K UL · 4×”。先用 CuNNy NVL 2倍，再用 Anime4K CNN_UL 2倍，不重复 Restore；默认关闭。持续低帧率会先取消叠加并提示，保留首选档位，仍可回原图或单独模型。叠加不保证优于单独模型，可能更柔或产生伪细节。详见 玻璃导航与叠加超分-2026-11-13.md。
