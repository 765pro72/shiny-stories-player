# 2026-11-15 创作、配音与文本往返

本轮为已有播放器追加功能。原社区译文与署名不修改，缺译不会伪装为已完成。

## 怪文书编辑

- 人物大小滑杆与百分比输入实时生效，每人独立，保存到工程；恢复 100% 可复位。
- 添加镜头内移动后，直接拖人物设置终点；紫色框和连线标明当前对象、起终点。点击已有段的“拖动设置终点”可继续改；“编辑镜头起点”或 Esc 返回初始站位。
- 身体、表情、视线、嘴型独立轨道；持续嘴型、定时字幕、音频、导入 Spine/图片等保持兼容。

## AI 创作台

入口：怪文书顶部“AI 创作”。各工具独立：扩写、全文案直接编排、提纲直接生成可播放剧情、润色、续写、脚本修复。脚本先在独立舞台预览，再追加到当前工程或新建工程，可撤销本次加入。

支持 OpenAI 兼容 Chat Completions、Responses、Anthropic Messages、Gemini 四种协议，提供美国、中国及本机服务的地址预设。模型名由用户填写或读取模型列表，不保证任意网关的私有扩展通用。API Key 只在会话内，不进入 localStorage、导出文案或工程。地址与模型可记住。

无 API 时选择任务，复制或下载提示词，交给聊天 AI；将其返回的文案／JSON 粘贴回来，校验并预览。无需先使用扩写。素材与动作必须从所选目录引用，模型不能指定任意文件或执行代码。

实现参考用户提供的 Gakumas-Player 的流程与宣传截图，未复制其源码和视觉设计。

## AI 配音

入口：怪文书顶部“AI 配音”。这是独立工具，不需要先用 AI 创作。

1. 展开“配音服务与音色库”，填写自己的服务与 Key。Fish Audio 默认 s2.1-pro-free，另列 s2.1-pro、drama-3、s2-pro、s1；也支持 OpenAI 兼容 /audio/speech 和本机服务。
2. 点击“从参考仓库读取角色音色”，或手动填写自己的音色 ID。本轮联网验证解析到 29 位角色的公开配置。音色是否仍公开、额度及计费以服务商为准。
3. 选择角色、输入朗读台词，可单独修正读音而保持字幕；生成后试听，再点“加入当前分镜”，或下载 MP3。
4. 可选择带动嘴型的角色，并按音频时长延长分镜。已有人工嘴型时间轴会保留，不覆盖；静态图片或无嘴型模型不会伪造动画。
5. 批量配音先读取队列、逐句选音色、再开始。已有配音／空白／定时字幕镜头跳过。停止保留已完成配音；剩余句子可以继续生成。单批最多 100 句。
6. 生成结果作为导入音频保存，保存或导出 .gwa 即随工程带走，之后可离线播放。Key 不写入文件。重新生成时旧声音素材仍在素材箱。

语音是 AI 合成，不是新的官方录音。无内置本地 TTS 权重，不宣称离线生成或一模一样的音色。没有真实付费 Key，本轮以模拟服务验证接口、音频解码、试听、批量中止、嘴型指令及归档；尚未实际付费验证第三方音色的听感。

参考：[Eidolon-SC](https://github.com/Sallyn0225/eidolon-sc)，上游代码 AGPL-3.0-or-later。这里按 [Fish Audio 公开 TTS API](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) 自行编写适配，没有复制上游服务代码。其角色配置仅由用户按需从原地址读取，界面保留来源；没有随包附带音色权重或上游作品素材。

## 剧情字幕与导出导入

- 事务所设置增加“剧情字幕”默认语言，支持中文、双语、日语原文及一键原文切换。与事务所语音字幕单独设置；剧情馆／相册的播放语言选择也会记住。
- 每篇剧情旁有“导出文本”菜单（日语原文／汉化）和“导入文本”。剧情馆、传统列表、卡片关联剧情均有入口。
- 导出 JSON 保留 story、id、original，内附填写、保存、导入、撤销说明。原文导出将 translation 留空，existingTranslation 只供参考；汉化导出包含已收录译文和本地补译并标明来源。
- 导入先核对剧情／行号／原文，先预览再应用；单篇入口拒绝其他剧情。空白不覆盖。沿用用户补译层与 before/after 日志、最近五批撤销，不改社区文件。
- 全部原文 ZIP 按篇装 JSON、README 和 manifest；有真实缺失会列明。生成过程可查看篇数和停止。本轮实际导出 10,906/10,906，缺失 0，约 37.4 MB。
