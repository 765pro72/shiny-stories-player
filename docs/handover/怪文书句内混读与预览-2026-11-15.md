# 怪文书 2026-11-15.4

## 同一句内指定日语和中文

入口：怪文书 → AI 创作 → AI 音声 → 打开音声创作 → 当前分镜 → 日语段＋中文段 · 整句合成。批量队列每句也有同样入口。

这里的日语段、中文段是同一句台词里的语言标注，不是新的台词或分镜，整句通过一次请求合成一条配音。

例如朗读框填写「プロデューサーさん、我爱你……今のは秘密です。」：先选中「我爱你」，展开分段设置，点击“把选中的文字设为中文段”。前后保留日语，这三个字标为中文，中文段直接填中文即可，系统自动注音。点“＋日语段”“＋中文段”可以继续添加，拖动或上下移调整顺序。默认生成整句的一条音频，使用一个音色、一次请求，不逐段合成后拼接。

中文段使用内置 pinyin-pro 3.29.5 自动注音（MIT 许可证随包）。读错时可展开“读音修正”，填写如 `wo3 ai4 ni3` 的声调拼音覆盖自动结果，程序转换为 Fish 的音素标记。日语读音修正填写假名，例如「今日」填写「きょう」。片段只有汉字且标为日语时必须提供假名，避免靠字形猜语言。无法自动注音、手动格式不对或兼容服务不能使用此协议时，明确报错，不会静默忽略。

画面字幕和朗读内容分别保存。分段标注保存在工程里，导出 .gwa 可带走。生成的声音可以先试听再加入当前镜头，修改读音后旧配音会被判为过期，需重新合成。测试验证了请求内容、实际音频载入、批量、保存和过期检查；音频采用模拟样本，没有调用付费服务，实际语言切换和发音效果仍须试听。

官方读音控制依据：
- https://docs.fish.audio/developer-guide/core-features/fine-grained-control/chinese
- https://docs.fish.audio/developer-guide/core-features/fine-grained-control/japanese
- https://docs.fish.audio/features/text-to-speech （language 参数只影响文本规范化，不能充当强制发音开关）

## 表情和动作

所有扩写、润色、续写、文案编排、提纲编排、修复及导演提示词统一要求：结合整段对话、角色性格、真实情绪、表面语气和转折安排演出。扩写的演出提示单独书写，不加入朗读文本。编排时发送当前模型的真实动作名、中文参考和所属轨道；不杜撰模型动作，不把 lip/face/eye 放进身体轨道，不每句话重复问好或夸张动作，连续情绪尽量衔接。规则改善选择依据，不代表已经人工审核每次 AI 生成的演出。

## 创作台与预览

分镜预览横跨整个创作区。使用下方导演、配音和填词工具时，默认收成顶部预览，可点击“展开预览”或关闭“预览跟随操作”。编辑配音队列时会预览对应镜头；同一工程的导演修改保留当前预览镜头，不再跳回第一镜。

“日语配音字幕填词”用于给缺少日语的旧台词补上日语，已有内容跳过，不生成音频。手动 JSON 粘贴和无需 API 的提示词入口保留在折叠项内。没有删除上游法定署名或第三方许可证；用户要求去掉的产品介绍文字已从界面移除，AI 教学段重新录制，逐帧采集时检查该文字没有重新出现。
