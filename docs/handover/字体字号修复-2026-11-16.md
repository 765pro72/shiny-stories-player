# 字体与字号修复（2026-11-16.2）

- 设置入口：事务所 → 看板设置 → 字体与字号。字体同时用于界面和剧情；界面字号80–150%、剧情字幕字号60–180%分别保存，恢复默认可一键还原。
- 新／旧官方剧情内核均使用中文实际字形测量、字形边距和明确行距，修复部分宋体／仿宋／圆体等顶部裁切和旧版两行重叠。姓名与正文按实际墨迹定位，避开框边及分隔线；姓名最大30逻辑像素，正文跟随字号。对话框只延伸正文区域，标题与分隔线不因拉伸向下压字。
- 怪文书和主页字幕同步字号；界面字号只调整文字，不缩放舞台画面。新控件、页面切换与窗口缩放重新计算文字基准，避免逐层叠加。
- 本机未安装的字体使用系统替代字体，安卓不保证存在Windows的宋体、楷体等。自定义字体仍需在当前设备安装。
- 实际回归：scripts/test-font-layout.cjs，六种预设、60/100/150/180%在新旧两种内核共48组；检查实际字形留白、姓名和正文间隔、屏幕边界；另检查字号控件、保存及新增控件不重复放大。输出exports/font-layout-verification.json和PNG截图。
- Windows和Android共用上述实现。Android为独立WebView＋内置Node本机服务，继续开发；手机不支持在应用内编辑源码后构建Windows程序。
- 没有修改剧情译文、用户作品或受保护超分目录；没有录制视频。用户现有程序未重启，重启仍须用户同意。
