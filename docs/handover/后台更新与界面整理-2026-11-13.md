# UI 2026-11-13.8：后台更新与声音界面

本次仅交付 Lite。没有修改原画、模型图集、翻译及其署名，也不改动原有下载资源。

## 更新

旧超时报错没有记录来源，不能从用户截图倒查到底哪一个请求失败。旧更新器对整个 GitHub 资料包设置固定 120 秒总超时；解包和目录重建又在 Electron 主线程执行，长下载或重建期间体验不清楚。

现在 update-background.cjs 管理独立 Worker 更新任务。关闭进度面板、切换模块不终止任务；各页面从主进程读取当前状态，右下角可重新打开。进度包含来源、已接收 MB、官方分片计数、正在核对的角色以及运行时间。失败显示具体来源及中文说明，可重试；已成功的分片和未变更的资料包可复用。进度记录在“下载资源/update-status.json”，资料包和分片在同目录 update-sources，版本目录在 updates。

网络通过 Electron net.fetch 使用应用网络会话/系统代理设置。requestBytes 区分连接等待、接收停滞及总体上限，暂时失败最多三次尝试；HTTP 404 等永久失败不反复等待。总上限并非取消，正常持续接收的资料包不再受旧 120 秒限制。

启动检查合并并发请求，手动更新可复用刚完成的检查，避免重复扫描同一批分片。更新各类索引和汉化；不会批量保存音频、图集和卡面媒体。任何来源局部失败保留对应旧资料并在结果列警告。新版本仍先写独立目录、最后原子切换 active-data。

后台的范围是“应用仍在运行时”；完全退出 EXE 会中断任务，下次显示中断状态并允许重试。不是常驻系统服务，也不在用户未点击时自动下载全部资源。完成后提供“重新载入目录”，不强行打断正在播放的剧情。

## 声音界面

电话保留官方电话演出的图像和播放器，目录采用与语音馆相同的标题、渐变卡面、四统计、索引/列表布局。删除遗留 phone-filter display:block 与新网格的冲突；索引按钮占满侧栏，窄屏转横向分类，不再占据整块页面中间。电话列表使用轻量图标和角色头像。

按用户最终截图，只把看板设置中的“背景音乐音量”放到左列，与字幕语言、语音音量的左边缘对齐；仍保留原来的控件宽度和音乐状态。主页右侧音乐按钮与原开关行为保持，未另设独立入口或浮层。保留自动压低音乐、循环和偏好持久化。没有减少页面动效。
