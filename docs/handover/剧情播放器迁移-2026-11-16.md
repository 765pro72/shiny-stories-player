# 普通剧情播放器迁移（2026-11-16.1）

普通官方剧情默认改用 AsaHikari/ShinyScenarioViewer 的控制器，固定提交 `66e8d7607eb4380762420bc64a593f7898d586c1`。原有剧情馆、卡片关联入口、汉化、补译、字幕语言偏好、导入／导出、音量、全屏和实时画质设置继续使用本项目接口。主页及怪文书使用各自的播放器，没有因本次迁移更换。

用户本轮补充：以后发布不再生成 ZIP。正式发布、助手生成的新版程序与可分享修复包统一使用 7z，并保留文件夹；压缩包从程序文件清单生成，不依赖旧 ZIP、不混入用户下载或配置。旧记录中的 `zip` 字段兼容读取，新的字段与显示格式为 7z。更新下载读取上游资料包不受发布格式影响。

## 使用与回退

剧情下方“播放设置”可切换 ShinyScenarioViewer 与“兼容旧版”。切换会从头加载当前话，字幕和本机补译仍保留；不会重启软件。源码与许可按钮在应用内显示说明。旧控制器保留在 `public/player/legacy.html`，新入口为 `public/player/main.html`。

上游代码、AGPL-3.0-only 许可、原始说明及致谢位于 `public/player/scenario/`；本地适配位于 `scenario-bridge.js`、`scenario-text.js` 和 `engine-controls.js`。对应可编辑源码、依赖锁文件、构建与测试脚本均在本分享包的 `resources/app/` 中，执行 `npm install` 后可通过 `npm run release` 构建（正式发布仍需要本地资源门禁）。游戏素材版权不随代码许可转移。

## 迁移解决和保留的行为

- 新控制器处理 `middleFg`、`voiceKeep`、文本延迟、剧情记录、选择分支和各类转场。旧版在只有 `bgEffect`、没有 `effectValue` 的某些等待轨会抛异常，新控制器在正式脚本中通过。
- 汉化匹配兼顾同编号多句，支持中文／日文／双语、即时本机补译、记录中重听语音及共享界面字体。
- 每个角色独立管理嘴型与声音结束事件。已有 `stand_gasha` 动态嘴型兼容沿用本项目 HomeVoicePolicy；制作人与无发声的听话者不套用另一人的口型。
- 复用相同角色模型；延迟文本与嘴型计时器在换轨／退出时清理，旧声音结束不能关闭新声音对应的嘴型。
- 保留主音量、全屏、Anime4K／ArtCNN 与原图。测试抓取实际画面像素，防止仅检查“开关已开启”而漏掉黑屏。
- 本地原始资源优先；更新后的目录、译文和实际脚本统一经现有服务器读取。离线下载的共享扫描器增加 `middleFg`、新式影片／音效与衣装分类处理，后续新资源继承相同规则，未将 pause／off 等指令误当文件。

全部 10,906 篇本地脚本、738,237 条轨道已通过路径转换。额外完整播放了 16 篇真实官方剧情，覆盖中层前景、延迟文本、语音保持、选择分支、条件命令、影片、六类背景效果与连续文本；不等于逐篇完整观看了全部剧情。

独立 Electron 测试覆盖原剧情馆、卡片关联入口、新旧内核切换、即时字幕／补译、重复台词编号、音量、自动模式、记录重听、制作人气泡、双人轮流说话、全屏、两种画质引擎与更新后数据指针。更新测试包含新依赖递归下载、缓存复用、元数据激活、更新失败保留旧数据及后台进度恢复。最终固定回归、发布门禁与压缩包结果以 `exports/发布核验-2026-11-16.1.json` 为准；本说明中的预期不能代替最终报告。

没有调用付费 AI 接口，未更改社区译文或署名，未修改用户怪文书／收藏／密钥，也未重启用户正在运行的软件。未修改受保护的超分目录。

## 缺失资料必须明确

1. 《The Straylight》第 6 话「GET SET」（`game_event_communications/400103307.json`）脚本在本地。其结尾 `stillType: game_event_communications` 按新控制器转换为过场影片与独立音效；本轮对影片、音效路径重新请求官方和镜像，仍未取得有效文件。加载失败会提示并跳过这段影片，其余剧情继续；不能说这段影片已修复或已补齐。旧版将它推导成 JPEG 的记录不再视为正确素材路径。
2. `data/no-script.json` 的 26 个 2019 万圣节根条目没有独立文本脚本；其相册问题描述及成功／失败分支是不同数据。重新核对后，这 26 项对应的 52 个成功／失败分支都已在可播放目录，不能把 26 个根条目说成丢失了 26 篇完整剧情。此次只复查了其中一项根脚本的两种路径，不声称穷举了所有未知路径。
3. 原公开资料的 42 条耳语缺 voiceHash、卡图 2040210180 待资料等缺口仍保留。缺失卡图不再使已知对应剧情整篇中断；没有用其他卡图冒充。
4. 本轮发现下载清单漏扫的两张前景图（009971、007711）已从有效官方来源补入缓存与下载清单。全游戏覆盖、全部翻译完成、所有衣装逐帧无误均不在已验证结论中。

详细现场记录：`exports/scenario-player-verification.json`、`scenario-update-verification.json`、`scenario-official-verification.json` 和 `scenario-missing-recheck-2026-11-16.json`。后续更新仍取决于公开上游是否收录、官方／镜像能否取得有效文件；遇到未知脚本字段仍需再次验证。
