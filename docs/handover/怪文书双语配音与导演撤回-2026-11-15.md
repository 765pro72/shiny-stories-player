# UI 2026-11-15.3

本轮为接手 GPT 实现与验证；没有修改社区译文，也没有把 AI 同人台词当作官方原文。

## 双语台词与配音

- 完整对话生成日语台词和中文字幕；分镜及定时字幕的 `text` 为画面字幕，`original` 为日语台词。旧 v1 工程不必转换，缺少日语时仍可手动编辑、选择中文或独立补译。
- AI 创作台增加独立“日语台词”工具，可处理现有工程或创作草稿；只填缺失的日语。提供 API、提示词往返、校验和撤销，不要求先运行其他创作工具。
- 配音默认读取日语；保留中文配音。每句可以选日语、中文字幕或自定义朗读，直接修改输入框就是实际发送给语音服务的内容；画面字幕单独保留。缺少所选语言时阻止空文本请求，不偷偷降为中文。
- 批量队列增加“取消勾选制作人台词”，支持制作人、製作人、プロデューサー、Producer、P 及括号备注。仅取消制作人的勾选，其他角色保持原样，允许再手动选回。
- 已配音句子可显示、修改并重新生成；旧音频素材保留。定时字幕也支持，修复生成后编辑失效的旧字幕对象引用。日语、字幕或自定义朗读内容变化后，过时 AI 配音会被跳过。
- 音频、两种台词及朗读设置随 `.gwa` 保存。API Key 仍只在当前会话内存中；没有将密钥写进工程、提示词、浏览器存储或发布包。

## 日语姓名与对制作人的称呼

资料依据：本地游戏原文 `cache/json/` 与主页台词，正式姓名另与 `research/idols.json` 和[官方偶像介绍](https://shinycolors.idolmaster-official.jp/idol/)对照。联网参考[呼称表](https://wikiwiki.jp/shinycolors/アイドル呼称一覧)后，逐人回查本地原文；29 人（28 位本家偶像＋叶月）均有相应台词依据。逐条例句和文件位置保存在 `data/story-character-language-evidence.json`，不把代词每一次出现都断言为在称呼制作人。

完整表可在创作台“查看正式日语姓名与对制作人的称呼参考”展开。规则随扩写、全文案编排、续写、润色、导演、补译及无 API 提示词一起发送。比如凛世为「プロデューサーさま」，结华有「Ｐたん」，日花为「プロデューサーさん」，美琴为「プロデューサー」；冬优子按场合使用不同称呼。罕见粗口不强行塞进普通对白。联动角色称呼没有核实，不编造官方结论。

日语台词出现中文显示名、或与角色常用称呼不符时给出核对提示，不自动篡改用户文本。AI 仍可能写错语气、指代和称呼，需要创作者审阅。界面称“日语台词”，不冒称“官方原文”。

## 导演与撤回

- 导演区新增“直接应用分镜脚本到编辑器”，支持当前 changes 修改结果与完整分镜工程／脚本。直接写回，不重复追加；相邻按钮可撤回上次应用。
- 导演操作结果和错误提示显示在本区，避免只在对话框顶部给出消息而看不到。相同结果不重复执行；载入新工程时清理上一份待应用结果。
- 编辑器“撤回上一步”“重做”保存最近 50 步，支持 Ctrl+Z / Ctrl+Shift+Z。移动拖动合并为一步，连续文本输入合并；文本框仍保留原生文本撤销。生成／导入正在进行时不能跨任务撤回。

## 素材整理与后续更新

- “情绪标注”改为“标注”。所有素材类型都能标注、写自定义备注和收藏；备注及标注加入搜索，提供只看收藏。原有音乐标注保留。
- 用户记录按素材来源和路径保存，新增资料不会清掉旧备注、收藏；桌面保存沿用现有跨端口恢复机制。
- 内容更新共用 `story-material-index.cjs`，将新模型、背景、音乐、音效加入怪文书完整目录，不固定在旧 3220 套模型列表。界面重开素材库会读取最新目录，旧激活目录也与内置基线合并。
- 分类与“出现于”来自真实脚本。新增素材未取得脚本时显示无引用记录，不猜情绪或剧情名；以后打开脚本会自动补充引用。原始剧情音效路径为 `sounds/se/event/`，本轮一并修正；模型也记录实际剧情引用。
- 元数据版 v2 按剧情存引用，重复更新不增加重复次数。本轮现场 7125 项有引用／用途的素材，10906 篇脚本均已取得引用记录；这是本地状态，轻量版以后缺少新脚本时不能声称引用已全部补齐。剧情配音台词的数十万独立片段不塞进素材分类，避免目录膨胀和切换卡顿。

## 自动聊天嘴型

普通语音与自动聊天共用音频绑定的嘴型控制，按正在发声的角色驱动原生嘴型；恢复被待机／空轨打断的嘴型，并恢复重复动作的 loop/alpha。停止、换人、下一人发声及播放结束会解除绑定。

实际五人同屏、ArtCNN→Anime4K 测试以原速播放美琴／日花对话，强制清空两人的嘴型轨后，仍验证到各自持续变化的嘴部附件；另有自动交替、点击中断、不连播重复对话的回归。没有把这说成所有服装逐条人工验证；静态图片、无嘴型的 gasha 模型无法凭空生成原生说话动作。

### 逐句指定语言／故意混说
用户可在提纲或全文案指定“只有我爱你用中文，其余对白用日语”。生成规则要求该句 `speech:{language:"zh"}`，其他句 `ja`；一句中混说可用 `custom` 的精确朗读文本。字幕和日语参考台词仍分别保存，补译不改变朗读选择。接口只收到实际朗读文本，发音准确度取决于语音服务；未冒称实测第三方音色对该例句的发音。
