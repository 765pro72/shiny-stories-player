# UI 2026-11-15.14

剧情馆里的本机怪文书改为普通剧情共用的 `#viewer` 播放弹窗：标题、收藏、全屏、下一句、自动播放、字幕语言、音量、从头播放、画质设置及独立滚动的对话记录使用同一套外壳。点击作品不再离开目录，关闭保留搜索、筛选和阅读位置；“继续编辑”是独立入口。原编辑器的观看链接仍兼容。

新增只读 `custom-story-viewer` 页面，通过同源消息连接播放控件。复用现有舞台、动作衔接、配音绑定、自动嘴型、制作人提示音与BGM逻辑；不会改写工程来切换字幕或音量。主对白与定时字幕可显示中文、日文、双语；没有日语字段时显示已有文本，不自动编造日语。支持打包在 .gwa 内的素材。

怪文书增加本篇文本导出和带预览的补译导入，仍走统一文本往返界面。补译保存在本机覆盖层并记录变更日志，可撤销；不覆盖原工程、配音或社区译文。导出行保留镜头／字幕编号，`originalProvided` 区分实际日语与无日语时的原始文本。每篇作品旁也可单独导出原文／汉化文本及导入。

全屏细边来自舞台1136×640与显示器比例差异露出的浅色底。编辑器全屏背景改为深色；新只读播放器从根页面起使用无边距深色画布、保持比例，剩余空间是正常深色留边。没有改生成脚本、裁切人物或拉伸官方素材。

助手原来在样式表尚未加载时就显示原生 popover，切页／慢加载可能出现巨大的无样式聊天内容。现在等样式就绪再挂载显示，并为样式和回复解析模块加版本标识。加载失败不显示无样式窗口。

截图中的“解释文字＋工具JSON”也曾被当作普通聊天，工具没有运行。共用回复解析器支持外层解释和代码围栏，提取完整任务结构后仍走既有工具与权限校验；格式截断明确失败，不把指令当聊天正文。旧聊天只整理显示，不执行历史指令。

助手设置新增“清除对话”，先在窗口内确认。清除全部偶像的聊天，停止正在运行的本次任务并阻止延迟回复重新出现；连接设置、任务文件和修复产物保留，可在任务列表重新查看。清除状态跨导航与重开保存。

回归覆盖真实 Spine 与工程内WAV在共用窗口播放和嘴型、主对白／定时中日字幕、音量、收藏、自动／下一句／重播、全屏、关闭卸载、目录保留与编辑兼容；带预览补译不改原归档。助手以延迟样式加载、文字包裹JSON的真实检索流程、清除期间的延迟回复及跨页验证。统一可信基础检查增加至17项。无付费AI调用、无新视频、无社区译文和原模型改动。最终发布以 `exports/发布核验-2026-11-15.14.json` 为准。
