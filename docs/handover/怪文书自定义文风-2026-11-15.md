# 怪文书自定义文风（UI 2026-11-15.5）

打开「怪文书 → AI 创作」，在「文风」选择「自定义文风」，下面直接填写要求。例如：

> 对白简短、贴近日常；用停顿和小动作表达心意，少旁白。前半轻松，结尾留一点余韵。

可描述对白、旁白、节奏、氛围、情绪表达和需要避免的写法。原有四种预设保留；切回预设不会删除自定义内容。

扩写、润色、续写、提纲生成分镜、全文案编排，以及复制／下载的任务提示词共用该设置。导演提示词也会带上文风，但未要求改动的台词保持原样；全文案编排仍逐句保留现有台词，修复脚本只修格式和无效引用。

文风随 AI 创作草稿自动保存，重新打开仍可继续使用，也包含在「导出创作草稿」的 JSON 中。API Key 不进入草稿。

真实 Electron 界面已验证自定义字段、API 请求内容、六种任务提示词、导演提示词、预设隔离和重新打开恢复；接口使用模拟回复，没有请求付费 AI。
