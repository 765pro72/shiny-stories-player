# 剧情播放器与全能音乐馆规范

本文档说明 283PRO 离线剧情解析渲染与全能音乐馆（Jukebox）的设计与技术规范。

---

## 1. 剧情播放引擎

- **内核目录**：`public/player/`
- **支持剧本类型**：
  - 官方偶像 Produce 剧情 (P-SSR / P-SR)
  - 官方 Support 偶像辅助剧情 (S-SSR / S-SR)
  - 官方活动剧情 (Event Stories)、主线剧情与越境时序篇章
  - 玩家怪文书与同人二创剧情 (Creative Stories)
- **多语言与双语字幕**：
  - 支持中日双语实时同屏对照。
  - 支持快捷键一键切换日文原版字幕 / 中文汉化字幕。
  - 具备缺行降级机制：官方未汉化句子自动显示日文原文，并支持在界面内直接补译回填。

---

## 2. 283 全能音乐馆 (Jukebox)

- **核心文件**：`public/music.js`、`public/music.css`
- **设计特色**：
  - 学园偶像大师风格黑胶拟真唱片机，包含旋转黑胶唱片、起落唱臂拟真动画与环境光晕反射。
  - **沉浸全屏播放排版**：严格保证在各类分辨率（1080p、2K、4K 及宽屏）下唱片、歌曲元数据与播放控制区域严格水平垂直居中。
- **音质与音效引擎**：
  - **沉浸环绕声** (Spatial Immersion)
  - **超清母带级** (Master Audio)
  - **极高 HQ** (High Quality 320k)
  - **臻音全景声** (Panoramic Sound)
  - 提供环境混响（演播厅、大剧场、排练室）与动态均衡器实时调节。
