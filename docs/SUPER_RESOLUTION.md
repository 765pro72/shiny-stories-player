# 实时超分辨率与图像增强规范

本文档记录项目中集成的实时着色器超分辨率（Anime4K、ArtCNN、AnimeSharpV4）的接入规范。

---

## 1. 超分着色器体系

- **Anime4K (WebGL)**：
  - 核心着色器：`Restore`、`Upscale`、`Deblur`。
  - 适用场景：全屏剧情播放时的实时画质重构，适合兼顾性能与线条锐化。
- **ArtCNN**：
  - 基于轻量卷积神经网络片段着色器，专注立绘细节重绘与去噪。
- **AnimeSharpV4**：
  - 高画质增强模式，优化卡面相册与衣装室动态展示。

---

## 2. 性能与多端调度策略

- **Windows 桌面端**：
  - 支持调用独显硬件加速（WebGL 2.0），默认开启高质量实时增强。
  - 允许在设置界面中自由调节抗锯齿级别与锐化阈值。
- **Android / 鸿蒙系统**：
  - 默认关闭重度着色器以避免 GPU 功耗过高，提供“标准 / 性能 / 增强”三档切换。
- **免责与职责范围（开发守则）**：
  - 本地离线镜像高清化超分辨率处理由专用离线流水线负责，严禁擅自修改 `cache-sr/`、`upscale-work/` 等超分训练工作区。
