# 怪文书二创与语音口型体系规范

本文档梳理《闪耀色彩播放器》中的怪文书（用户自定义剧情）创作系统、TTS 配音与口型同步规范。

---

## 1. 怪文书创作与剧情往返

- **双向往返机制**：
  - 支持在播放器内直接编辑、导演剧情节点（角色立绘、表情、台词、音效、BGM、背景图）。
  - 支持一键导出/导入标准的 JSON 剧情文本包，保证文本在桌面端、移动端与外部编辑器之间无损流通。
- **自定义文风支持**：
  - 预设经典风格滤镜与叙事模板，方便玩家快速生成高质量的偶像事务所日常或剧情番外。

---

## 2. TTS 配音与自动嘴型同步

- **语音合成支持**：
  - 支持本地与云端两套语音引擎，可为每位偶像绑定专属音色。
  - 支持句内混读（中日夹杂、英文缩写）与角色情绪参数微调。
- **动态嘴型动画生成**：
  - 根据音频波形与音素切分，实时映射 Live2D / Spine 模型的嘴型参数（`mouthOpen`、`mouthForm`）。
  - 支持固定嘴型兼容降级模式，确保在弱算力设备或无音频情况下也能自然衔接对话。
