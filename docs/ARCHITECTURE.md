# 系统架构与目录结构规范

本文档梳理《闪耀色彩播放器》的技术架构、双端运行时流程与工程目录规范。

---

## 1. 整体架构概览

本项目采用 **本地资源服务 + Web 前端展示 + 跨端原生外壳** 的统一架构：

```
+-------------------------------------------------------------------+
|                           客户端外壳                                |
|  - Windows: Electron (desktop.cjs)                                |
|  - Android: Node-Mobile 运行时 + 原生 WebView 容器                 |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                        本地 HTTP/WS 服务                          |
|  - server.cjs: 资源路由、剧情反代/离线镜像、音频流、WebSocket通信  |
|  - updater.cjs: 官方与社区翻译增量对账、热更新与素材补全           |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                         前端 Web 界面                              |
|  - public/index.html: 导航枢纽、主界面交互、助手气泡               |
|  - public/player/: 剧情解析与播放引擎 (Spine/Live2D/背景立绘)      |
|  - public/music.js & music.css: 拟真唱片机、黑胶唱臂、音质切换      |
|  - public/arcade.js: VIP游乐厅卡牌引擎 (掼蛋/斗地主/大富豪)        |
+-------------------------------------------------------------------+
```

---

## 2. 核心入口与脚本

| 入口文件 | 职责说明 |
| :--- | :--- |
| `desktop.cjs` | Windows Electron 桌面端主进程入口，管理窗口、快捷键、DPI 缩放与退出逻辑。 |
| `server.cjs` | 本地资源服务器核心，统一处理本地静态资源响应、跨域头、接口反代与离线缓存。 |
| `updater.cjs` | 公开数据与翻译更新模块，负责官方版本比对与增量下载。 |
| `scripts/release.cjs` | Windows 免安装绿色版发布打包工具（7-Zip 高强度固实压缩）。 |
| `scripts/build-android.cjs` | Android APK 交叉编译、打包、16KB 页对齐与 v3 证书签名全自动化脚本。 |
| `scripts/verify-offline.cjs` | 离线资源完整度自检工具。 |
| `scripts/audit-translation-status.cjs` | 翻译状态对账与缺失句统计。 |

---

## 3. 核心目录规划

- `public/`: 前端所有页面、样式表、脚本与播放器内核源码。
- `android/`: Android 原生壳工程、JNI 桥接层与 Node.js Mobile 构建配置。
- `scripts/`: 维护、构建、打包、校验与镜像下载工具脚本。
- `docs/`: 统一工程技术文档与历史开发归档。
- `translation-work/`: 汉化翻译台账、差异比对记录与回填导出。
- `cache/`: 离线镜像与下载的官方剧情/音频/立绘缓存。
- `dist/`: 最终产出的 Windows `.7z` 绿色包与 Android `.apk` 安装包。
