> 统二十有八神姝之明姿，纂四时岁会、巡涉八荒之青简。九韶备举，丹青毕陈。  
> 置诸案上几砚，纳诸掌中尺素，脱网罟之羁绁，启椟即聆钧天之奏。

### 壹 · 经纬百珍

* **星曜嘉会编**：备录列姝起居策问、岁时嘉飨与穷幽涉遐诸帙，累数百千卷，靡有孑遗。辞旨精微，两邦言辞互相映发。
* **韶乐广钧台**：范金合度，象璇玑玄石之回运，合历科韶濩于规矩。设周天回响、太清元音、极高金钟诸般发声之法，奏九韶以抚八表。
* **丹青云锦阁**：素缣写照，双面变幻；绘真容于寸楮，弄华彩于毫厘。兼具宛转形魄、步武容止之姿，顾盼生辉，宛立瑶台。
* **含章清音府**：私语偶语、云中寄声、群芳清谈，金声玉振，声容兼茂。设采风掇遗之术，脱略讹阙，皆可回填。
* **方博戏苑**：置叶子博塞、投琼争胜之艺，以适情怡性，不废雅趣。
* **随形周适**：无论崇楼邃阁、极目延揽，抑或微行幽室、随身提携，皆无损耗之虞，滑若流膏。
