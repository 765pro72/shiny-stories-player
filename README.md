# 《闪耀色彩·星曜绎韵录》 (Shiny Stories Player)

> 《偶像大师 闪耀色彩》（THE IDOLM@STER SHINY COLORS）二八三事务所之离线全能典藏录。  
> 通涉电脑端（Windows 绿色免装置）与手机、平板、鸿蒙诸般形制。  
> 披卷即阅，抚弦共听，无复网丝窒碍之虞。

---

### 🌟 核心景致（核心功能）

* **星图剧情馆（全量收录剧情）**：
  * 统揽二八三事务所全量官方偶像剧情、活动剧情、越境时序与主线剧本。
  * 内设精修中文汉化，中日双语字幕随心更迭。
* **二八三音乐馆 (Jukebox 黑胶鉴赏)**：
  * 学马风格黑胶拟真唱片机，全量偶像大师企划曲目在线与本地离线播放。
  * 设超清母带、沉浸环绕、极高 HQ、臻音全景声诸般音质引擎，如临舞台之侧。
* **仙姿画阁与衣装室（卡面相册与衣装）**：
  * 高清双卡面画廊、双卡面切换、动态卡面演出播放。
  * 支持偶像 3D / Spine 动态衣装模型试听与动作表情调试。
* **清音雅苑（全量语音馆）**：
  * 收录全部角色主界面、私语、电话、组合对话语音与同步字幕。
  * 设直接补译与回填导出法门，随时点勘缺漏。
* **二八三博戏坊（休闲游艺）**：
  * 斗地主、掼蛋 2v2、大富豪等多款内置同台卡牌游艺，闲暇小叙，相得益彰。
* **多端自适（多端适配优化）**：
  * **Windows 电脑端**：支持原生高分辨率（`Ctrl + +/- ` 自由无损缩放）、多屏与全屏沉浸播放。
  * **Android 移动端**：深度适配 20:9 / 21:9 全面屏与 16:10 / 3:2 平板；专为华为卓易通 / 鸿蒙容器降低能耗，流转丝滑。

### 🛠️ 本地演练与运行（本地开发与运行）

#### 环境需求
* Node.js >= 18
* Windows x64（运行桌面端）或 Android SDK / NDK（编译移动端）

#### 快速启动
```bash
# 安装依赖
npm install

# 启动本地开发服务与 Electron 桌面客户端
npm start

# 构建 Windows 发布包
npm run release

# 构建 Android APK 安装包
node scripts/build-android.cjs
```
